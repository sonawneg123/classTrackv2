# 🎓 ClassTrack AI

> AI-Powered Classroom Assignment Evaluation & Learning Management System

ClassTrack AI is a modern classroom management platform that helps teachers create classrooms, distribute assignments, automatically evaluate handwritten or typed submissions using AI, generate reports, and track student performance.

The platform provides separate portals for **Administrators**, **Teachers**, and **Students**, along with a secure enterprise-grade authentication system.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/ClassTrack-AI.git
```

---

## Backend

```bash
cd classTrackv1-backend/server

npm install

npm run dev
```

---

## Frontend

```bash
cd classTrackv1-frontend

npm install

npm run dev
```
